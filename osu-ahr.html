osu! Auto Host Rotate Bot

The osu! Auto Host Rotate bot is a fully automated multiplayer lobby manager built to keep games moving, fair, and competitive. It rotates hosts after each match, enforces configurable map regulations, manages map-pick and start timers, supports player voting, and automatically starts games when everyone is ready. Players can track their local ELO, ranks, win rates, streaks, playtime, and global map scores, while administrators have powerful tools to manage queues, lobby settings, map rules, deny lists, and random event probability. To keep matches fresh, the bot can trigger special rounds with Team VS, Combo, or Accuracy conditions, and balancing teams using each player’s local ELO before returning the lobby to its standard rotation.

Command reference

Click or tap a command to copy • Tab + Enter works too

Player Commands

  • !queue Show host queue.
  • !skip Vote to skip current host.
  • !autoskip on/off Automatically skips your turn.
  • !start Vote to start.
  • !abort Vote to abort a stuck match.
  • !regulations Show active map regulations.
  • !rank [username] [osu|taiko|catch|mania] Show local AHR ELO leaderboard rank.
  • !playtime / !pt [username] Show lobby session and total playtime.
  • !timeleft / !tl Show remaining time in the active match.
  • !lastscore / !ls Show the last lobby result.
  • !bestscore / !bs [username] Show global best score, accuracy, PP, mods, and placement on selected map.
  • !ostats / !os [username] [osu|taiko|catch|mania] Show ELO, LWS, matches, and win rate.
  • !top / !t [local] [osu|taiko|catch|mania] Show local ELO leaderboard.
  • !how / !h Explain ELO.
  • !bug Redirects user to the issue page on the Github repository.
  • !cmds Show the bot's command list.

Host Commands

  • !skip Immediately rotate host.
  • !start [seconds] Start after 0–120 seconds.
  • !stop Cancel the host’s start timer.
  • !update Refresh the selected beatmap.
  • !version / !v Show bot version.

Administrator Commands

  • *start Start immediately.
  • *skip Force host rotation.
  • *abort Force match abortion.
  • *close Close the lobby.
  • *order player1, player2, player3 Set queue order.
  • *resetelo confirm Reset all local competitive ELO/stats.
  • *eventchance 0-100 Set random-event percentage.

Lobby Locks

  • *keep size 1-16
  • *keep password [password]
  • *ranked on/off
  • *keep mods [mods...]
  • *keep title [title]
  • *no keep size|password|mod|title

Denylist

  • *denylist add [username]
  • *denylist remove [username]

Mode Values (*keep mode)

  • Team mode: 0 Head-to-Head, 1 Tag Co-op, 2 Team VS, 3 Tag Team VS
  • Win condition: 0 Score, 1 Accuracy, 2 Combo, 3 ScoreV2
